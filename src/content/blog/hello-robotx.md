## 从一个小问题开始

不必等到完全掌握某个领域才动笔。一段有用的代码、一个容易忽略的细节，都是很好的起点。

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("RobotX"))
```

代码可以运行，过程也值得记录。除了最终答案，我更希望保留“为什么这样做”。

## 把公式写清楚

行内公式可以自然地嵌入句子，例如 $E = mc^2$。

较长的推导则单独排版：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
